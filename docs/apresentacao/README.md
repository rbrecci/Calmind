# Apresentação final

PowerPoint, PDF ou Canva. Entregável da Sprint 3.

O cronograma reserva **dois ensaios** na semana 12. Não são enfeite: é onde se descobre que o roteiro tem 40 minutos e a banca deu 15.

**O ensaio precisa ser com o APK instalado no celular, não com emulador no notebook.** Demonstração que depende da máquina de uma pessoa é risco desnecessário no único dia que vale nota.

Três coisas que costumam faltar no slide e valem ponto:

1. Os quatro compromissos do produto, do `README.md` da raiz. É o que diferencia o Calmind de um app genérico de bem-estar.
2. O mapeamento dos cinco eixos de avaliação do item 2.4 para os requisitos que os atendem.
3. As limitações declaradas. Banca pergunta o que o trabalho não faz, e quem já respondeu por escrito responde melhor.
