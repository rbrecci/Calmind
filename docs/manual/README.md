# Manual do usuário

Entregável obrigatório da Sprint 3, item 2.1 da regulamentação. Rastreado como DA-10 em [`../planejamento/decisoes-abertas.md`](../planejamento/decisoes-abertas.md).

São dois manuais, não um: o paciente e o psicólogo usam o produto de formas opostas.

**Escrever junto com a funcionalidade, não no fim.** Manual escrito na última semana custa o dobro e sai errado, porque ninguém lembra mais do fluxo real. O caminho barato é capturar a tela quando ela fica pronta.

Aproveite os wireframes de [`../prototipo/wireframes.html`](../prototipo/wireframes.html): a ordem das telas ali já é a ordem natural do manual.
