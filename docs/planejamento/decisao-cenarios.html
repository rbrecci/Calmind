Sobreposição

A maior parte do trabalho é a mesma nos dois caminhos

idêntico nas duas rotas mesmo trabalho, tecnologia diferente só no A só no B

Contagem sobre as tarefas do cronograma acima, não sobre esforço nem linhas de código. Idêntico significa a mesma tarefa nas duas rotas. Equivalente significa o mesmo trabalho em tecnologia diferente, que custa parecido mas não é o mesmo aprendizado. Exclusivo é o que só existe em um dos caminhos.

O que realmente muda

A camada do cliente

A. Vue com Bootstrap no navegador, responsivo e mobile-first. Stack que o grupo já domina.

B. React Native rodando no aparelho. Conhecimento superficial no grupo, então a semana 1 é fundação pura.

O lembrete de medicação (RF-28)

A. Aviso dentro da aplicação, que só aparece quando a pessoa abre o sistema. Lembrete fraco para quem precisa lembrar de tomar remédio.

B. Notificação local agendada no aparelho, que dispara no horário mesmo sem internet. É o comportamento que o requisito descreve.

O painel do administrador

A. Só mais uma área da mesma aplicação web.

B. Aplicação web separada em Blade, sobre o mesmo backend. São 4 telas simples, e é justamente isso que fecha a exigência de sincronização entre mobile e web do item 2.2.

Quem carrega o cliente

A. Caio sozinho no frontend, com Mariana entrando de apoio nos dias de aula.

B. Caio e Mariana dividem o app o tempo todo, e Zanetti sai do backend por duas semanas para fazer o painel web.
