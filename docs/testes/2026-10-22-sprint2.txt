4. Integração web, API e banco
Roteiro em 22/10: a psicóloga fictícia semeada criou pela página web a tarefa de identificador 4. O POST autenticado do formulário /psychologist/tasks retornou 200 e o título apareceu na página. A paciente fictícia Elizabeth recebeu a tarefa com status pending em GET /patient/tasks e a concluiu em POST /patient/tasks/4/complete, que retornou 200 com status completed. A nova página /psychologist/tasks exibiu 'Concluída em 22/10/2026 19:31'.
Resultado: o mesmo registro foi escrito e lido nas camadas web, API e MySQL. O roteiro não prova que o comando de conclusão foi acionado pela interface móvel.

5. Escopo ainda sem prova

Nenhuma delas foi contabilizada como teste aprovado de funcionalidade entregue.
