Preços

Gratuito para quem procura ajuda. Sem preço em destaque no catálogo.

Paciente

Gratuito. O paciente não paga para usar o aplicativo: relatos, tarefas, agenda e conversa.

Consultas

O valor das consultas, quando houver, é combinado diretamente com cada psicólogo. O catálogo não exibe preço em destaque.

Psicólogo

As condições para psicólogos serão informadas no aplicativo. Esta página apresenta o protótipo do Calmind.

Perguntas sobre preço

O Calmind custa alguma coisa para o paciente?

O uso do aplicativo é gratuito para o paciente. Isso não significa que as consultas com profissionais sejam gratuitas.

Preciso informar cartão para criar a conta?

Não. Criar a conta leva menos de dois minutos e não pede cartão.
